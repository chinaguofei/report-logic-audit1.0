# 逻辑病灶库（体裁无关）

> 用法：逐条对表，命中的记「位置 + 原文 + 代号 + 修法」。不必全查——先按**这篇文章想说服谁**挑相关的层：说服人信事实 → E 层；说服人信道理 → R 层；说服人愿意读下去 → X 层。
>
> 每条都给了**可直接问出口的问句**。问句比定义好用：定义让人点头，问句让人露馅。

## 分层

| 层 | 查什么 | 典型症状 | 归属关卡 |
|---|---|---|---|
| E · 证据层 | 证据在不在、够不够、真不真 | 数字没出处、个案当普遍、图截断轴 | 一 |
| R · 推理层 | 从证据到主张的那一步走得通吗 | 相关当因果、中间环节缺失、归因单一 | 四 · 五 |
| X · 表达层 | 话有没有被说糊涂 | 「可能/有望」连用、倍与 % 混、反问当论据 | 二 · 四 |

---

## E 层 · 证据

| 代号 | 病征 | 问句（问到就现形） | 修法 |
|---|---|---|---|
| E1 | 无源断言 | 「这个数从哪来的？口径是什么？」 | 补出处、口径、日期；补不上就降级为「据…估算」并说明方法 |
| E2 | 单例外推 | 「一个案例能代表这一类吗？样本多少？」 | 补样本量与选择标准，或把结论收窄到该案例 |
| E3 | 选择性引用 | 「反面的数据有没有？为什么只给这一段区间？」 | 补反向证据并解释；至少给出区间而非点值 |
| E4 | 数据与结论反向 | 「表里这条趋势和图旁边那句话是一个方向吗？」 | 改结论，别改数据 |
| E5 | 统计量不可复算 | 「这个均值/合计/增速，用文中明细能算出来吗？」 | 报告内明细必须能复算；算不出先查数据处理代码 |
| E6 | 基准漂移 | 「两处数字是同一天、同一口径吗？」 | 统一基准日；派生量一次性重算 |
| E7 | 样本偏误 | 「被统计的对象是怎么选进来的？漏了谁？」 | 说明抽样框与幸存者偏差方向 |
| E8 | 图表误导 | 「纵轴从几开始？双轴是不是各放大了一倍？」 | 轴从 0 起或明确截断标注；双轴写明换算关系 |

## R 层 · 推理

| 代号 | 病征 | 问句 | 修法 |
|---|---|---|---|
| R1 | 相关当因果 | 「同时发生就说明是它引起的？机制是什么？」 | 给机制 + 排除共同原因（第三变量） |
| R2 | 充分必要混淆 | 「有这个条件就一定成？没有就一定不成？」 | 分清「充分」「必要」「贡献」三档，用词跟着改 |
| R3 | 中间环节缺失 | 「从 A 到 B，中间经过谁？多久？会不会卡住？」 | 补传导链每一环，标注时滞与卡点 |
| R4 | 循环论证 | 「把结论换个说法当理由了吧？」 | 找独立于结论的证据 |
| R5 | 以偏概全 | 「局部现象凭什么推整体？」 | 说明局部与整体的比例关系 |
| R6 | 假两难 | 「只有这两种选择？第三种呢？」 | 列出被省略的选项 |
| R7 | 滑坡 | 「第一步到第二步凭什么必然？」 | 每一级都补概率或条件，不给就删链 |
| R8 | 诉诸权威/共识 | 「大家都这么说，所以对？他们的利益立场是什么？」 | 拆解其论证过程，只借事实不借结论 |
| R9 | 类比不当 | 「这两件事在关键变量上真的同构吗？」 | 指明同构点与不同构点，不同构处不得推结论 |
| R10 | 归因单一 | 「行业涨它涨，凭什么是它自己强？」 | 拆分 β 与 α，给同业对照基线 |
| R11 | 时间外推 | 「过去三年这样，第四年就一定这样？」 | 给三情景 + 各情景成立条件 |
| R12 | 反事实不可检验 | 「这个说法能不能被任何数据推翻？如果不能，它说了什么？」 | 补可证伪判据，或降级为定性判断 |
| R13 | 量级不匹配 | 「效应量只有 3%，结论却写成『决定性』？」 | 让用词强度对齐效应量级 |
| R14 | 定义偷换 | 「前后两处『X』是同一个意思吗？」 | 首次出现处定义，全文锁定同一含义 |
| R15 | 时间悖论 | 「拿后发生的事解释先发生的事？」 | 校准时序，区分「事后归因」与「事前预期」 |
| R16 | 幸存者偏差 | 「只数了成功者？失败的那批去哪了？」 | 补分母 |

## X 层 · 表达

| 代号 | 病征 | 问句 | 修法 |
|---|---|---|---|
| X1 | 模糊限定词堆叠 | 「『有望可能或将』——到底几成把握？」 | 换成概率区间或条件句：「若 X，则 Y」 |
| X2 | 倍与 % 混用 | 「增长 1.5 倍，是变成 2.5 倍还是 1.5 倍？」 | 增速一律 %，倍数只用于规模关系 |
| X3 | 否定不当 | 「双重否定读出来是肯定还是否定？」 | 拆成两句直陈 |
| X4 | 主体缺失 | 「『预计将提升』——谁预计？提升谁？」 | 补主语与宾语 |
| X5 | 概念空转 | 「这个词全文出现 12 次，第一次出现时解释了吗？」 | 首现处一句话定义 + 一个例子 |
| X6 | 修辞替代论证 | 「排比、反问、感叹能当证据用吗？」 | 保留修辞，但旁边补证据句 |
| X7 | 段落失去主干 | 「这段的第一句和最后一句，是不是同一件事？」 | 一段一义，首句立论、末句落地 |
| X8 | 指代漂移 | 「『该产品』指的是上一段的哪个？」 | 把代词换成名词 |

## 高频组合（比单条更值得警觉）

| 组合 | 长什么样 | 为什么危险 |
|---|---|---|
| E1 + R12 | 没有出处的数字 + 不可证伪的结论 | 整段无法被检验，等于没写 |
| R1 + R10 | 行业涨 → 归因公司竞争力 | β 当 α，最常见的假 α |
| E5 + E6 | 统计量算不出 + 基准日不一致 | 通常是数据处理 bug，而非笔误 |
| X1 + R11 | 「有望持续高增」+ 线性外推 | 用模糊词掩护无依据的外推 |
| R2 + R13 | 「必然受益」+ 效应量 1% | 量级撑不起用词 |
| R4 + R8 | 引用共识证明共识 | 论证原地打转 |

## 判定纪律

1. **只报能指出"错在哪一步"的**。说不出哪一步断，就不是逻辑问题，是文风问题，进 🔵。
2. **每条必须给最小改法**：改一个词、补一句话、换一个数、删一段。给不出改法的问题，多半是自己没想清。
3. **不确定写「未确认」**：标出依据薄弱点（缺哪份材料），不要用「似乎有问题」蒙过去。
4. **反例优先**：如果一条批评能被原文另一处反驳，先自己核一遍，别让用户替你核。
