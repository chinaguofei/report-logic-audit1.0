小节标题固定为「**生产基地布局与投产进度**」，置于第一章第 1 段之后、最新行情段之前，**六个要素缺一不可**：

| # | 要素 | 必写内容 | 数据来源等级 |
|---|---|---|---|
| 1 | **基地清单与投产状态** | 逐个列：地点 / 实施主体 / 项目名 / 投资额 / 设计产能 / 达到可使用状态日期。开头一句给总数：**已投产 N 个、在建 M 个**。若公司未以"基地个数"口径披露，必须**声明本报告采用的口径**（厂区口径 or 城市口径），不得含糊合并 | A（募投专项核查报告、年报、施工许可公告） |

| 6 | **利好/利空判定** | 必须给一句结论，不许只罗列事实。按下方判定表落判断 + 一条可跟踪指标 | D（本报告综合判断） |

**判定表（产能利用率 × 产销率 × 库存方向，三维，不许各写各的）**

| 产能利用率 | 产销率 | 存货余额 / 周转天数 | 判定 | 标准表述 |
|---|---|---|---|---|
| 上行 | ≥95% 或 >100% | 下降 / 加快 | **利好（强）** | 产能被订单消化，产销两旺且库存出清，投产即达产 |
| 上行 | ≥95% 或 >100% | 上升 / 变慢 | **中性偏空** | 产销率高但库存在积累，增长或靠备货与压货，需查收入确认与应收 |
| 上行 | <90% | 上升 / 变慢 | **中性偏空** | 量增靠铺货或压价，需求未真正消化 |
| 上行 | <90% | 下降 / 加快 | 中性 | 主动控货、以销定产，看下季订单能否接续 |
| 下行 | ≥95% 或 >100% | 下降 / 加快 | **中性偏多** | 主动控产去库存，产能留待需求回暖 |
| 下行 | ≥95% 或 >100% | 上升 / 变慢 | **利空** | 产销数字好看但库存在涨，去库存不成立，实为滞销或被外购/转售扭曲 |
| 下行 | <90% | 上升 / 变慢 | **利空（强）** | 投产了没跑满、货还压着，折旧先行、收入滞后，扩产≠增长 |
| 下行 | <90% | 下降 / 加快 | 中性偏空 | 主动减产清库，短期止血但收入承压 |

> **矛盾处置（v1.1.7 核心规则）**：产销率是**运营口径**（区间数，可含外购成品转售、样品、售后换货），存货余额是**审计口径的时点余额**（可核）。两者方向冲突时，**以存货余额 + 周转天数定调，产销率仅作辅助**，并必须在正文写清冲突原因，常见三种：①销量含**外购/外协转售**，不消耗自产成品；②成品已发货计入**发出商品**，收入未确认，仍挂在存货；③为下季订单**提前备货**（原材料/在产品上升）。**禁止**在存货上升时仍写"处于去库存状态"。
>
> **补充硬约束**：①若"当年转固"叠加"产能利用率下行"，一律按**利空**表述，并量化折旧影响；②并购取得的产能不计入"自建投产"，须单列并说明商誉/摊销；③未披露的产能数字标「未确认」，**不得用行业均值倒推**（2026-10-19 供应链误判教训同源）；④**库存数据必取自定期报告资产负债表**，不得用"产销率倒推库存"（2026-11-03 隆利科技教训：产销率 103.48% 与存货 +37.59% 并存，倒推会得出相反结论）。

## 4. 硬规则（8 条，逐条都曾出过事故；第 7 条 v1.1.6、第 8 条 v1.1.7 新增）

1. **口径纪律**：全文只能有一个"所处行业"（主业占比过半者）；其余只能作"工艺邻接/对照口径"。标题、行业界定、TAM、同业池、估值锚必须同向；主口径的表/图必须排在邻接口径之前。
2. **单位纪律**：增速一律 `%`，禁止"倍/翻倍"；"倍"只用于估值倍数与规模关系；同一数值组内单位必须唯一。图脚本用 `_assert_units()` 前置断言，交付前跑 `check_fig_units.py`。
3. **章序纪律**：一章一主题；**并题优先于拆章**（标题与内容不符时改标题，不新增章节）；小结=结论章，必须在估值之后；**风险提示=正文末章**。
4. **图表化优先**：能用图表表达的不要用文字（六维打分、订单、产业链、利润构成、季节性、三情景）；每张图必须紧跟一句结论，不得空投。
5. **季节性论证**（八章③必写）：收入侧季节性用单季营收差分实证（Q4 占比、区间、Q4/Q1 倍数、失效年份反例）；股价侧季节性用月度收益统计并**明确说明统计显著性**；最后必须翻译成"验证时间轴 + 可证伪判据"，不得用季节性直接推股价。
6. **数据分级**：A=法定披露；B=第三方机构/主流财经媒体；C=券商研报与一致预期（仅参照）；D=本报告自算（须标假设）。正文引用的每个关键数字都要能落到某一级。
7. **产能六要素必写**（v1.1.6 立、v1.1.7 扩，一章小节）：基地清单与投产状态 / 产能·产量·销量三量与产能利用率·产销率 / **库存变动验证（存货余额·周转天数·结构）** / 新增产能来源（自建·并购·租赁）/ 在建项目时间表与转固影响 / 利好利空判定。**只写"生产基地位于某区域"这类概括句视为缺项**（2026-11-03 隆利科技报告即因此被用户退回，详见 §1.1）。
8. **库存必交叉验证**（v1.1.7）：产销率与存货余额方向冲突时，**以存货余额（审计口径时点余额）与存货周转天数为准**，产销率只作辅助；存货上升而产销率 >100% 时，**禁止**写"在去库存"，须解释口径差（外购转售 / 发出商品 / 提前备货）。库存数据必须取定期报告资产负债表，**不得由产销率倒推**（2026-11-03 隆利科技：产销率 103.48%，存货同期 +37.59%、周转由 27.1 天放慢至 33.6 天，倒推会得出相反结论）。
