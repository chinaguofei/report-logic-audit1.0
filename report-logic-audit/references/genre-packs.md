# 体裁包 · 不同文章该查什么

> 六关是通用骨架，体裁包决定「必写要素」「专属判据」「默认禁令」。审核前先定体裁——**同一句话在研报里是错，在评论里可能没问题**（例：「我认为」在研报里是失格，在时评里是必需）。

## 怎么定体裁

用户没说时，按标题 + 首段 + 结构特征判，判完在报告抬头写一行「体裁：X（依据：…）」。**判错体裁会导致整份审核跑偏**，不确定就问一句，不要猜两次。

| 信号 | 体裁 |
|---|---|
| 有股票代码 / 目标价 / 估值 / 同业对标 / 「投资建议」 | 个股或行业研报 |
| 有摘要、关键词、参考文献、样本量、方法 | 学术论文 / 综述 |
| 有「方案背景—目标—实施—预算—风险」 | 方案 / 可行性 |
| 有「一、二、三」+ 发文对象 + 工作要求 | 公文 / 汇报 |
| 通篇解释「是什么、为什么、怎么运作」，无立场主张 | 科普 / 解释文 |
| 有明确立场、针对近期事件或争议 | 评论 / 时评 |
| 有品牌、产品卖点、行动号召（CTA） | 白皮书 / 营销 |
| 「各位、今天我讲三点」+ 口语短句 | 讲稿 / 培训 |
| 「第一步…第二步…注意事项…常见报错」 | 教程 / SOP |

---

## 1 · 个股 / 行业研报（research）

**必写要素**：公司概况｜市场共识与分歧｜核心逻辑｜财务矩阵与质量甄别｜行业景气（空间/六维/产业链/订单）｜行业均值对照｜同业对标｜技术分析与估值（含三情景）｜小结｜风险提示（正文末章）｜数据来源与免责

**专属判据**
- 全文只能有一个「所处行业」；主业占比过半才可占该位，其余降为工艺/邻接（口径矩阵）
- 标题声明的主次顺序 = 图表物理顺序
- 结论章必须在估值之后；风险提示必须是正文末章
- 估值必须给三情景 + 各情景成立条件，不能只给一个目标价
- 财务结论必须能被 16 季矩阵复算

**高频病灶**：β 当 α｜同业池与标题行业不一致｜PE 口径两种并列｜市值在三处不同｜图内单位混用

**默认 `--must-have`**：财务质量甄别、估值通道分析、免责声明

---

## 2 · 评论 / 时评 / 议论文（essay）

**必写要素**：争议是什么（谁跟谁在争）｜我的主张（一句话）｜最强反方观点（不是稻草人）｜我的回应｜证据｜限定条件（在什么范围内成立）｜落点（读者该改变什么判断）

**专属判据**
- **反方必须以其最强形态出现**。把对手写成傻子 = 论证无效（稻草人谬误）
- 主张强度必须与证据强度同级：有统计支持可写「趋势」，只有个案只能写「有一例」
- 立场文允许「我认为」，但每处「我认为」后必须跟一个可被检验的理由
- 时评必须交代事实基础的时间点（截至 X 日）

**高频病灶**：情绪替代论证｜只打稻草人｜用极端个案推整体｜把「应该」偷换成「将会」

**默认 `--must-have`**：反方观点、限定条件

---

## 3 · 学术论文 / 文献综述（academic）

**必写要素**：研究问题｜文献缺口｜方法（样本/变量/模型）｜结果｜稳健性｜局限｜结论与政策/实践含义｜参考文献

**专属判据**
- 每条结论必须能追溯到具体表格列（结果章与表格一一对应）
- 「显著」必须带统计量与样本量，不能只说显著
- 相关性结论不得写成因果，除非有识别策略（IV/DID/RDD/控制变量说明）
- 局限章不得为空；必须写明外部效度边界
- 引用文献必须在参考文献表中存在（反向也要查：列了但正文没引）

**高频病灶**：结论超出样本范围｜稳健性只做一处｜把「不显著」解释成「无影响」｜图表与正文数字不一致

**默认 `--must-have`**：研究方法、参考文献、研究局限

---

## 4 · 科普 / 解释文（explainer）

**必写要素**：它是什么（一句话）｜为什么重要｜怎么运作（机制图或类比）｜边界与误解｜常见错误认知｜进一步了解路径

**专属判据**
- **首现术语必须给定义 + 一个例子**，全文同一术语不得换义
- 类比必须标注「类比到哪为止」（哪一点不再同构）
- 每个「所以」前后要能独立成句读懂，不能靠读者补常识
- 数字必须给参照系（1 GWh 是多少家庭的用电？）
- 不得出现「显然」「众所周知」——科普文里这两个词等于没解释

**高频病灶**：概念密度过高｜类比过度外推｜省略前提导致结论跳步｜把行业宣传口径当事实

**默认 `--must-have`**：定义、边界

---

## 5 · 方案 / 可行性 / 立项（plan）

**必写要素**：问题与背景｜目标（可量化）｜方案与备选方案对比｜实施路径与里程碑｜资源与预算｜风险与应对｜验收标准｜责任分工

**专属判据**
- 目标必须可验收（有数字、有时间、有责任人），「提升效率」不算目标
- 必须给至少一个备选方案并说明为何不选——只给一个方案等于没做方案
- 风险章必须给应对动作，不能只列风险名称
- 预算与里程碑必须能对上：每笔钱对应一个交付物
- 「预期效果」必须给测算口径，不能只给结论数字

**高频病灶**：目标不可验收｜只列风险不给对策｜预算与进度脱节｜收益无测算假设

**默认 `--must-have`**：风险、预算、验收

---

## 6 · 汇报 / 公文 / 工作总结（report-gov）

**必写要素**：结论先行（领导先看这段）｜基本情况｜主要做法｜成效（可核数据）｜存在问题｜下一步｜请示事项（如有）

**专属判据**
- **结论必须在最前**（与研报相反：研报结论在估值之后，公文结论在第一段）
- 成效必须有可核数据，且与上期可比
- 「存在问题」不得空泛，必须具体到事项与责任主体
- 请示事项必须明确「要什么」（批钱/批人/批权限），不能只描述困难
- 数字口径必须与本单位的统计制度一致（谁的口径要写明）

**高频病灶**：通篇过程无结论｜成效形容词化｜问题写成客观原因｜请示无具体诉求

**默认 `--must-have`**：存在问题、下一步

---

## 7 · 白皮书 / 营销文案（copy）

**必写要素**：读者处境｜问题定义｜我们的解法｜证据（客户案例/测试数据）｜竞品差异｜适用与不适用场景｜下一步动作

**专属判据**
- 每个绝对化用词（「唯一」「首个」「最好」）必须有可核查依据，否则删
- 客户案例必须写明规模与条件，不能用「某大型企业」代替
- 差异点必须是对手做不到的，不是对手没说的
- **不适用场景必须写**——没有边界的宣称反而降低可信度
- 不得用行业预测冒充已发生事实

**高频病灶**：形容词堆叠无证据｜案例不可核｜把功能当价值｜适用边界缺失

**默认 `--must-have`**：案例、适用场景

---

## 8 · 讲稿 / 培训稿（speech）

**必写要素**：开场钩子｜今天讲几件事（明示结构）｜每件事的结论 + 例子｜记忆点（一句话）｜行动建议｜时间控制

**专属判据**
- 一句话长度：书面长句必须拆成可念的短句（超过 40 字的句子标出来）
- 每个抽象概念后面必须跟一个具体例子（听众无法回看）
- 结构必须口头明示（「第一…第二…」），不能靠排版层级
- 数字必须说人话（「3.2 亿」→「相当于每个中国人 2 块钱」）

**高频病灶**：书面语密度过高｜层级靠标题不靠口播｜例子集中在前半段｜结尾无行动建议

**默认 `--must-have`**：行动建议

---

## 9 · 教程 / SOP / 操作手册（howto）

**必写要素**：适用版本与环境｜前置条件｜步骤（可照做）｜每步的预期结果｜验证方法｜常见报错与处理｜回滚方案

**专属判据**
- 每一步必须**可验证**：做完能看到什么（输出、截图、状态）
- 命令与路径必须完整可复制，不能有「相应目录」这类占位
- 必须写明版本号；版本不明则标注「以 X 版本验证」
- 失败路径必须覆盖（报错 → 原因 → 处理）
- 破坏性操作必须给回滚步骤，且回滚在危险操作之前出现

**高频病灶**：步骤跳跃（省略中间态）｜占位符残留｜只写成功路径｜版本缺失

**默认 `--must-have`**：前置条件、常见报错

## 跨体裁的通用禁令（任何体裁都要查）

1. **占位符残留**：`[[`、`{{`、`TODO`、`XX`、`（待补）`
2. **悬空引用**：「见第 X 章」「如前所述」「见图 N」，被指对象必须存在
3. **编号断裂**：章节、图、表、脚注编号连续且唯一
4. **图/表无解读**：每张图表之后必须有一句结论，不能只放图
5. **摘要与结论不一致**：开头说的和结尾说的必须是同一件事
6. **数据不可复算**：文中给的均值/合计/增速，用文中明细要能算出来
7. **口径未声明**：含税/不含税、同比/环比、年度/单季、装机/中标
8. **「倍」与「%」混用**：增速一律 %，倍数只用于规模关系
9. **自相矛盾**：同一主题前文说升、后文说降，或结论与摘要唱反调（机器初筛 `R17-CONTRA` / `C-ABS-CONCL-*`）

## 10 · 外文（英文）审核要点

六关**语义推理层与语言无关**——论点—证据闭环、逻辑链条、推理终结等由 LLM 直接读英文文本判定，换语言只是换输入。但**格式关（check_format.py）是语言专属的**，必须显式切到英文模式：

- **格式审校**：`python check_format.py article_en.md --lang en`
  - 跳过全部中文专属关（错别字词表、全角、中英文空格、中文语境英文词、eastAsia 字体）；
  - 改跑英文专属关：**拼写**（pyspellchecker，缺依赖自动跳过并提示）、**标点前多余空格**、**行内连续空格**。
  - 不传 `--lang` 时默认 `zh`，英文文档会几乎零命中——**英文文档务必带 `--lang en`**。
- **机械六关（audit_docx.py）**：`python audit_docx.py article_en.md --lang en`
  - 跳过中文专属的「自相矛盾」机械关（依赖 3–4 字中文窗口）；其余结构关（章节/图表/单位/来源/必写要素）按 CJK 标记判定，英文文档多数自然不触发，安全不误报。
  - 语义矛盾、论据强度等仍由 LLM 六关推理覆盖，不丢失。
- **体裁判定**：英文文章的体裁信号与中文同构（摘要/参考文献→学术；股票代码/目标价→研报；CTA/卖点→营销）。`--genre` 仍可用 `essay / academic / research / plan / report-gov / copy / speech / howto`。
- **依赖**：英文拼写检查需 `pip install pyspellchecker`（纯 Python、离线词库、无网络请求）；未装则格式关给出「跳过拼写」提示，不影响中文路径。
