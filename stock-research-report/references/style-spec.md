## 同比变化率折线图规格（2026-09-10 新增，勿改）

- 两条折线：**营收同比**（实线 lw 2.4）+ **归母同比**（虚线 lw 2.0）
- 横轴 16 个季度，**时间正序（早→晚）**——注意与矩阵表的「最新在左」方向相反
- **0 轴分区着色**：0 轴以上 `#FDECEA` 淡红底，以下 `#E9F7EF` 淡绿底；0 轴 `#333333` 实线 lw 1.2
- 线段与数据点按所在区间着色：**正值 C0392B 红 / 负值 00913F 绿**（符合红涨绿跌）
- 数据点边长 s=34，白描边 0.8；末点旁标注最新值（带 +/− 号）
- 图幅 15.75 × 5.2 inch，dpi 100，白底；标题 bold 14pt 深灰
- y 轴标题「同比增速（%）」，网格仅横向 α0.25 虚线；隐去上/右边框
- 缺值季度传 `None` → 断线不画 0

## 正文内联着色标记

`build_report.py` 的 `add_runs()` 支持在文本中内联标记，用正则 `re.split(r"(<r>.*?</r>|<g>.*?</g>|<b>.*?</b>)", text, flags=re.S)` 解析：

| 标记 | 效果 |
|---|---|
| `<r>…</r>` | 红色 C0392B（涨/正） |
| `<g>…</g>` | 绿色 00913F（跌/负） |
| `<b>…</b>` | 粗体 |

注意标记必须成对闭合，且 `re.S` 使 `.` 可跨行。
