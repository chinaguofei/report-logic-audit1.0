## 页面结构（自上而下，缺一不可）

1. **标题**：`{公司简称}（{代码}）`，居中，24px 加粗
2. **矩阵表**：蓝头 × 5 指标行 × N 季（默认 16 季，最新在左）
3. **「指标」tab 组**：5 个标签，激活态蓝底白字，**默认选中「营收同比」**
4. **折线图**：所选指标的单线趋势图
5. 页脚：数据来源 + 口径说明（灰字）

## 矩阵表（固定 5 行，顺序勿改）

```
毛利率 / 营收同比 / 扣非同比 / 扣非TTM / 股东变化率
```

- 表头底纹 `#1E6FFF` 白字加粗；单元格边框 `#E5E6EB`
- 着色：**营收同比、扣非同比、扣非TTM、股东变化率按正负标色**（正红 `#E64545` / 负绿 `#00A65A`，股东变化率红=增加/筹码分散、绿=减少/筹码集中）；**毛利率行深色不标色**
- 数值格式：百分比两位小数（51.68%）；TTM 两位小数 + 亿（0.53亿）；无数据 `--` 灰色
- 点击表格行 = 切换图表（与 tab 联动）

## 折线图

- **蓝色单线** `#1E6FFF`，线宽 2.6；数据点蓝底白描边圆点（r 4.6）
- 浅灰横向网格 `#E5E6EB`；**0 轴线加深** `#C9CDD4`；y 轴标签灰 `#86909C`
- x 轴为季度（时间正序，早→晚，与矩阵表左右相反）；**不额外添加表外季度**
- 悬浮提示：`{季度}：{数值}`
- y 轴范围自适应（含 12% 边距，刻度取 1/2/2.5/5 整步长）

## 交互

- 点 tab 或表格行切图；图表淡入动画；无外部依赖（纯 HTML+CSS+SVG，离线可开）

## 数据规则

- 数值必须与研报第四章矩阵同源同值；数值顺序与 QUARTERS（最新在左）一一对应
- 扣非TTM = 滚动四季度扣非合计；缺失填 `None`（表中显示 `--`，图中断开不连线）
- 股东变化率 = 季末股东户数环比（与研报矩阵「户数环比」行同源同值），取各季度末披露值、与上一季末对比；上市前季度或未披露填 `None`
- 交付：`~/Desktop/WB/{公司简称}{代码}_指标切换图.html`
