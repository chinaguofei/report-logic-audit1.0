# 更新记录

## 1.1.0 — 2026-10-28

**新增 · 格式审校（模式三，`scripts/check_format.py`）**
- 四组检查：错别字与易混词（高置信词对约 40 条 + 语境类）/ 全角字符 / 标题层级（跳级、正文误用标题样式）/ 字体字号行距与中英文空格规范
- `--fix`（docx 专属）只统一中文字体与正文行距（落在占多数的值），落地前后逐段比对文字，多一个字符整份放弃；字号、错别字、全角字符、标题层级永不自动改
- 无 🔴 阻断档：格式问题不阻断交付，退出码恒 0（`--fix` 文字校验失败时返回 1）
- `.docx` 全项；`.md` / `.txt` 做文字层三组检查

## 1.0.0 — 2026-10-28

首个公开版本。

**六关审校**
- 论点—证据闭环 / 概念与口径一致 / 结构完整与衔接 / 逻辑链条 / 推理终结 / 数据与图文一致
- 输出分级清单（🔴 阻断 / 🟡 须修 / 🔵 建议），每条带定位、原文、病灶代号、最小改法
- 附**证伪台账**：每条主结论一行，写清"什么情况算错、看什么指标、什么时候看"

**推理终结（本版核心）**
- 五落点检查：依据 / 机制 / 条件边界 / 反例处理 / 可证伪判据
- 三档裁定：已终结 / 半终结 / 未终结
- 识别无连接词的判断句（"X 是核心变量""拐点已至"），不只认"因此/说明"

**三个环节**
- 论证骨架：章—字数—占比—图表—断言—断言密度，标出编号异常、空壳章、结论倾倒区、承重章
- 逻辑总结五问：一句话主张 / 分论点与证据等级 / 验证路径 / 承重点 / 三句话版
- 润色模式：只改表达层，四条硬约束（数字不动 / 删除类不自动 / 论证段只报告 / 落地后重跑审校）

**体裁适配**
- 9 种体裁包：研报、评论、学术、科普、方案、公文、文案、讲稿、教程
- 同一句话在不同体裁判定相反（"我认为"在评论里必需、在研报里是病灶；公文要求结论先行、评论要求结论后置）
- 研报档附加：行业口径矩阵、主次顺序、模板完整性

**其他**
- 32 条病灶库（E 证据 8 / R 推理 16 / X 表达 8），每条附可直接问出口的问句
- 5 个脚本，兼容 `.docx / .md / .txt / .html`
- 自带故意写坏的样例 `examples/sample-bad-article.md`，装完即可自测

**已知边界**
- 脚本给位置，人给结论；`SUGGEST` 有误报
- 术语统一不自动猜（无分词库时只会产出噪声），需 `--term-group` 指定
- 图内文字需绘图脚本按约定写常量才能校验
- 润色只处理单 run 文本，跨 run 位置只报告不改
